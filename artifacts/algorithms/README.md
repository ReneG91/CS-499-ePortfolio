# Algorithms and Data Structures

## CS 320 Task Application

This artifact was originally developed during CS 320:
Software Testing, Automation, and Quality Assurance.

The application manages tasks using Java and demonstrates
the use of data structures and algorithms to organize,
retrieve, and maintain information.

During CS 499, I enhanced the application to improve
its efficiency, functionality, and maintainability.

## Enhancements

- HashMap-based task management
- Task searching
- Sorting tasks by name or ID
- Improved error handling and testing
