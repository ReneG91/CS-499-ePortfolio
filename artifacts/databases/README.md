# Database Development

## CS 360 Android Inventory Application

This artifact was originally developed during CS 360: Mobile Architecture and Programming.

The application uses Java and SQLite to manage inventory information, including item names, quantities, and prices.

During CS 499, I enhanced the application to improve database functionality, data accuracy, and usability.

## Enhancements

- SQLite inventory management
- Inventory searching
- Low-stock inventory filtering
- Improved input validation
